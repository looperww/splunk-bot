# Web Server Log Investigation

Use when investigating application or web-server alerts. Focus on request paths, HTTP methods, response codes, user agents, source IPs, authentication context, and suspicious payload indicators.

Start with aggregated request patterns and narrow to suspicious source/request/time combinations before retrieving raw events.
